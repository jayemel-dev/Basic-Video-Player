
# Basic Video Player

This is a simple program that does just what you think.

It contains features such as queues, shuffling, video playback, volume control and video selection. 

It uses video files from your computer. The valid file types are: mp4, mkv, mov, and avi.

The path to these can be entered into the 'settings.json', or from a prompt in the program. Or you can upload videos into the 'Videos' folder in the program directory.

The controls are uncomplicated. 

A - Play previous video.
D - Play next video.
S - Shuffle program (if shuffle is enabled in settings).
R - Replay Video.
SPACE - Pause.
↑ - Volume up.
↓ - Volume down.
← - Playback.
→ - Skip forwards.
